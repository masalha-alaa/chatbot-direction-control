Privacy Policy

Last updated: August 26, 2026

Chatbot Direction Control is a browser extension that adds text-direction and alignment controls to supported chatbot websites. The extension is designed to operate locally in your browser.

Data collection

Chatbot Direction Control does not collect, transmit, sell, or share personal information, chatbot messages, browsing history, settings, or other user data.

Local storage

The extension uses Chrome's local extension storage to remember per-message direction choices so they can be restored when you revisit a conversation. This information remains in your browser and is not transmitted by the extension to external servers.

Network communication

The extension does not operate an external server and does not send analytics, telemetry, message content, or stored direction preferences to third parties.

Website access

The extension runs only on the supported chatbot websites declared in its Chrome extension manifest: ChatGPT, Gemini, Claude, and Grok. It reads and modifies page elements only as needed to provide its direction and alignment controls.

Third-party services

The extension does not integrate with advertising, analytics, tracking, or data-broker services. The chatbot websites themselves are independent services and are governed by their own privacy policies.

Changes to this policy

If the extension's data practices change, this policy will be updated to describe those changes.

Source code and contact

The source code is publicly available on GitHub. For questions, bug reports, or support requests, use the repository's issue tracker.
